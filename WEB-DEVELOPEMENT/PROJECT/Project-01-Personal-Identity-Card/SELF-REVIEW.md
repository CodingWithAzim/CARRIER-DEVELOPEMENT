# Project 01 — Self Review

Before moving to Project 02, check:

- [ ] I can explain every major HTML element I used.
- [ ] I can explain my CSS variables.
- [ ] I used semantic HTML instead of unnecessary `<div>` elements.
- [ ] The page works on mobile and desktop.
- [ ] There is no horizontal scrolling.
- [ ] The heading hierarchy makes sense.
- [ ] Links are keyboard accessible.
- [ ] Focus is clearly visible.
- [ ] Text has strong enough contrast.
- [ ] I tested at least one narrow mobile width.
- [ ] I rebuilt the page once without looking at the reference.
- [ ] I changed the design enough to make a personal version.

## Questions

2. Why is `<article>` reasonable for each skill item?

4. Which styles belong in reusable variables?
5. Which part of the design creates the strongest visual hierarchy?
