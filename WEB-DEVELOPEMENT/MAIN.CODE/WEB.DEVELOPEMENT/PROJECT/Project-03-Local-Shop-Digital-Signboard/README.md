# Project 03 — Local Shop Digital Signboard

A complete reference implementation for the third project in the learning ladder.

## Learning method

### Pass 1 — Study
Open `index.html` and `style.css`. Read the structure first, then the CSS.
Ask yourself why each semantic element, layout rule, spacing choice, and responsive rule exists.

### Pass 2 — Rebuild
Create a separate copy and rebuild the interface yourself while using this project as a reference when you get stuck.

### Pass 3 — From memory
Close the reference and create your own local-business signboard for a different business. Change the typography, color system, content, layout proportions, and visual motif.

## Suggested custom rebuilds

- Pharmacy / medicine store
- Tailor / clothing shop
- Bakery
- Mobile repair shop
- Neighborhood stationery store

## Main skills

Semantic HTML, accessibility basics, CSS Grid/Flexbox, responsive layout, visual hierarchy, CSS variables, custom illustrations with CSS, hover/focus states, reduced-motion support, and business-oriented CTA thinking.

## Important

This reference version intentionally contains finished code so you can study it. Your second and third pass should be your own implementation.
