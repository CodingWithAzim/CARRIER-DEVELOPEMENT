# CSS Grid — Complete Learning Pack

A hands-on CSS Grid course from absolute beginner to advanced layout engineering.

## How to use
1. Start with `01-basics`.
2. Open each `.html` file in a browser.
3. Read the matching notes and change the CSS yourself.
4. Continue in order.
5. Complete `10-practice` without copying the answers.
6. Finish `09-project` as the final project.

## Golden rule

Grid is best for **two-dimensional layout**: rows + columns together.

Flexbox is usually best for **one-dimensional layout**: a row OR a column.

Do not memorize properties mechanically. Change one value at a time in DevTools and observe what moves.
