# CSS Grid Practice

## Level 1
1. Make a 2-column layout.
2. Make a 4-column equal card grid.
3. Add a 20px gap.
4. Center the content of all cards.
5. Make the first card span two columns.

## Level 2
6. Rebuild a dashboard with header/sidebar/main/footer.
7. Make the cards responsive using auto-fit + minmax.
8. Rebuild the same dashboard using grid-template-areas.
9. Add an implicit row and control its size.
10. Compare auto-fit and auto-fill.

## Level 3
11. Create a magazine layout with a lead story spanning 2 columns.
12. Use named grid lines for a two-column article layout.
13. Build aligned cards with subgrid.
14. Build a responsive portfolio without using fixed card widths.
15. Recreate your own real website section using Grid.

## Debug challenge
Take a layout that overflows horizontally. Find which minimum track or item is causing it. Test:
- `minmax(0, 1fr)`
- `min-width: 0`
- smaller minimums
- content wrapping

## No-copy challenge
Do the final project from memory after finishing the lessons.
