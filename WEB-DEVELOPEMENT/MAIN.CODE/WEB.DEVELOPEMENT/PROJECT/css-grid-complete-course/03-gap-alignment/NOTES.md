# Gap and alignment

## Gap
- `gap`
- `row-gap`
- `column-gap`

## Item alignment
Affects content inside each grid item:
- `justify-items`
- `align-items`
- `place-items`

## Grid alignment
Moves the grid tracks as a whole:
- `justify-content`
- `align-content`
- `place-content`

## Self alignment
Affects one item:
- `justify-self`
- `align-self`
- `place-self`

### Axis reminder
In a normal horizontal writing mode:
- inline axis ≈ left/right
- block axis ≈ top/bottom

Grid alignment properties are logical rather than simply "horizontal" and "vertical".
