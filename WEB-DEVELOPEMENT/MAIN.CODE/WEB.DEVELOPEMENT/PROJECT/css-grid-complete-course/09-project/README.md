# Final Project — Responsive Portfolio Dashboard

Build a portfolio/dashboard page using CSS Grid.

## Requirements
- Header
- Sidebar
- Hero/profile section
- Skills section
- Project cards
- Statistics
- Footer
- Responsive mobile layout
- At least one `grid-template-areas` layout
- At least one `repeat(auto-fit, minmax(...))` layout
- At least one item spanning multiple columns
- Use semantic HTML
- Keep DOM order logical

## Bonus
- Add a theme switch
- Add a project filter
- Add a chart-like grid
- Add `subgrid` to align project card internals
