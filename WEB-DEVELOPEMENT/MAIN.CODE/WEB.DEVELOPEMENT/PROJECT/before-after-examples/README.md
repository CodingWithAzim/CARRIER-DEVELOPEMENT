# CSS ::before and ::after — Full Examples

Open each folder and run `index.html` in your browser.

01 - Glow: `::before` creates a blurred glow.
02 - Decorative Line: `::before` creates a top line.
03 - Overlay: `::before` adds a dark overlay over an image.
04 - Dot Pattern: `body::before` creates a subtle dotted texture.
05 - Button Arrow: `::after` adds an arrow without extra HTML.
06 - Hover Effect: `::before` becomes a light overlay on hover.
07 - Number Label: `::before` adds `01` before a heading.
08 - Combined: `::before` and `::after` create two decoration layers, plus `::after` on a button adds an arrow.

Core idea:
BEFORE -> element's content -> AFTER
