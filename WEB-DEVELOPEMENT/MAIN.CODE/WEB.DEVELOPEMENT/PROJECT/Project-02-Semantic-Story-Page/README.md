# Project 02 — Semantic Story Page

## How to use this project

This is the **full reference implementation**. Read it first, understand it, then rebuild it yourself without copying line-by-line.

### 3-pass method

1. **Reference pass:** open `index.html` and `style.css`, inspect every section and ask why each HTML element exists.
2. **Rebuild pass:** create a new folder and reproduce the page from memory plus your understanding.
3. **Independent pass:** close the reference and build a new story page with your own topic, wording, image direction, colors, and layout decisions.

## Main lesson

Do not treat HTML as a collection of `<div>` elements. This project introduces semantic page structure such as:

- `header`
- `nav`
- `main`
- `article`
- `section`
- `aside`
- `figure` / `figcaption`
- `blockquote`
- `footer`
- `time`
- `address`

The design also introduces an editorial reading experience, sticky section navigation, responsive layout transformation, focus states, reduced-motion support, and accessible image alternatives.
