# Project 02 — Self Review

Before moving to Project 03, answer these without looking at the reference.

## HTML
- Can I explain why the page uses `article` instead of only `div`?
- Can I explain the role of `section`, `aside`, `figure`, and `figcaption`?
- Is the heading order logical?

## CSS
- Can I explain the grid columns in `.story-layout`?
- Why is the story navigation sticky on larger screens?
- What changes below 800px?
- What changes below 560px?

## Accessibility
- Can I navigate the page with only a keyboard?
- Is the image alt text meaningful?
- Is focus visible?
- What happens when a user prefers reduced motion?

## Design
- Is the reading width comfortable?
- Does the visual hierarchy guide the eye?
- Does the mobile layout feel intentionally redesigned rather than merely squeezed?

Create a second story page on a completely different topic without opening the reference implementation.
