প্রতিটি উদাহরণের পাশে লেখা আছে “এখানে কেন ব্যবহার করেছি?” এবং ঠিক নিচেই সারমর্ম — যাতে concept + real use একসাথে বোঝো।

মূল ধারণা
aspect-ratio: 1;

Width : Height = 1 : 1 → Width যত, Height-ও তত।

01

BASIC

সবচেয়ে সহজ উদাহরণ

Height না লিখে ratio দিয়ে Height ঠিক করা।

CODE + RESULT

.box {
  width: 220px;
  aspect-ratio: 1;
}
220 × 220

এখানে কেন ব্যবহার করেছি?

আমরা শুধু width: 220px দিয়েছি। Height সরাসরি দিইনি। aspect-ratio: 1 CSS-কে বলছে: Width ও Height সমান রাখো।

220px width→1 : 1→220px height
সারমর্ম — এই জায়গার ব্যবহার

যখন box-কে সবসময় square রাখতে চাই, Width বদলালেও Height যেন সেই অনুযায়ী বদলায়—তখন aspect-ratio: 1 ব্যবহার করি।

02

COMPARE

Manual Height বনাম aspect-ratio

দুটোর কাজ চোখে দেখে তুলনা করো।

A — MANUAL HEIGHT

.box {
  width: 220px;
  height: 150px;
}
220 × 150
সারমর্ম — এখানে কী হচ্ছে?

Width ও Height দুটোই fixed। Width বদলালেও Height 150px-ই থাকবে; তাই proportion নিজে থেকে বজায় থাকবে না।

B — ASPECT-RATIO

.box {
  width: 220px;
  aspect-ratio: 1;
}
220 × 220
সারমর্ম — এখানে কী হচ্ছে?

Height fixed নয়। Width বদলালে 1:1 ratio অনুযায়ী Height-ও বদলায়; তাই square shape বজায় থাকে।

03

RATIO

Ratio বদলালে কী হয়?

1 শুধু square-এর জন্য নয়। Ratio বদলালে Width ও Height-এর সম্পর্ক বদলায়।

1 / 1Square
1 : 1
সারমর্ম — কখন?

Width = Height। Avatar, icon box, square card ইত্যাদিতে useful।

2 / 1Wide
2 : 1
সারমর্ম — কখন?

Width Height-এর দ্বিগুণ। Banner, horizontal thumbnail ইত্যাদিতে useful।

1 / 2Tall
1 : 2
সারমর্ম — কখন?

Height Width-এর দ্বিগুণ। Portrait বা vertical card-এ useful।

16 / 9Media
16 : 9
সারমর্ম — কখন?

Video/media frame-এর proportion ধরে রাখতে খুব useful।

04

REAL PROJECT

তোমার Identity Card-এ ব্যবহার

এখন তোমার আসল project-এর তিনটি জায়গা একসাথে দেখো।

01 — AVATAR

.avatar {
  width: 72px;
  aspect-ratio: 1;
}
72 × 72

এখানে কেন ব্যবহার করেছি?

Avatar-এর Width 72px। আমরা চাই Height-ও 72px হোক। তাই Height আলাদা করে না লিখে 1:1 ratio দেওয়া হয়েছে।

সারমর্ম — এই জায়গার ব্যবহার

Avatar-কে square রাখা যায়। পরে Width 60px বা 100px করলেও Height automatically একই হবে।

02 — CARD GLOW

.card-glow {
  width: 220px;
  aspect-ratio: 1;
  border-radius: 50%;
}
220 × 220

এখানে কেন ব্যবহার করেছি?

Glow-কে গোল করতে Width ও Height সমান দরকার। প্রথমে aspect-ratio: 1 220×220 বানায়, তারপর border-radius: 50% এটাকে circle করে।

সারমর্ম — এই জায়গার ব্যবহার

Equal width + height থাকার কারণে border-radius: 50% দিলে perfect circular glow পাওয়া যায়।

03 — STATUS DOT

.status-dot {
  width: 7px;
  aspect-ratio: 1;
  border-radius: 50%;
}
Available

এখানে কেন ব্যবহার করেছি?

Status dot ছোট circular indicator। Width 7px হলে Height-ও 7px দরকার, তাই 1:1 ratio দেওয়া হয়েছে।

সারমর্ম — এই জায়গার ব্যবহার

Dot-কে perfectly round রাখা যায় এবং পরে Width বদলালেও Height automatically বদলায়।

05

RESPONSIVE

Responsive design-এ আসল শক্তি

Width fluid হলেও proportion ধরে রাখা।

16 : 9
responsive frame
.media {
  width: 100%;
  aspect-ratio: 16 / 9;
}

এখানে কেন ব্যবহার করেছি?

width: 100% screen/container অনুযায়ী box-কে ছোট-বড় হতে দেয়। aspect-ratio: 16 / 9 Height-কে সেই Width-এর সঙ্গে একই proportion-এ রাখে।

সারমর্ম — Responsive use

Fluid Width + fixed ratio = responsive shape। তাই image, video, banner, thumbnail-এর proportion ঠিক থাকে।

06

EXPERIMENT

নিজে পরিবর্তন করে দেখো

এখান থেকে concept সবচেয়ে ভালোভাবে মনে থাকবে।

.experiment-shape {
  width: 300px;
  aspect-ratio: 1;
}

শুধু aspect-ratio বদলে একে একে পরীক্ষা করো:

12 / 11 / 216 / 9
সারমর্ম — কী শিখবে?

aspect-ratio কোনো size নয়; এটি Width ও Height-এর সম্পর্ক ঠিক করে। Ratio বদলালে একই Width থেকেও Height বদলায়।

KHATA NOTE

খাতায় লেখার জন্য শেষ সারমর্ম

aspect-ratio→ Width ও Height-এর অনুপাত ঠিক করে।
aspect-ratio: 1;→ 1 : 1 → Width = Height
width: 220px + aspect-ratio: 1→ 220 × 220
aspect-ratio: 16 / 9→ responsive media proportion
width: 100% + aspect-ratio→ Width fluid, proportion fixed
মনে রাখবে: aspect-ratio = “Width বদলালেও Height-কে নির্দিষ্ট অনুপাতে রাখার নিয়ম।”
