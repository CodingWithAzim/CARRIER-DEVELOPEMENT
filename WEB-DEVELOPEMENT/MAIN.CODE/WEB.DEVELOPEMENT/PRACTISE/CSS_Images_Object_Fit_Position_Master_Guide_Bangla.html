1. Mental Model — Box আর Image এক জিনিস নয়

┌─────────────────────────────┐
│        IMAGE CONTENT        │
│                             │  ← img element-এর BOX
└─────────────────────────────┘

width / height      → box-এর size
aspect-ratio        → box-এর width:height ratio
object-fit          → image content কীভাবে box-এ fit হবে
object-position     → fit/crop হওয়ার পর কোন অংশ কোথায় থাকবে
overflow            → box-এর বাইরে যাওয়া অংশ দেখা যাবে কি না
transform: scale()  → rendered image-কে বড়/ছোট করা
মূল কথা: width/height = box-এর মাপ; object-fit = fit করার নিয়ম; object-position = অবস্থান।

2. object-fit — Image কীভাবে fit হবে?

এটি <img> ও <video>-এর content-কে তার box-এর মধ্যে কীভাবে রাখা হবে তা নিয়ন্ত্রণ করে।

fill

Default। পুরো box ভরবে; ratio বদলাতে পারে।

cover

পুরো box ভরবে; ratio থাকবে; কিছু অংশ crop হতে পারে।

contain

পুরো image দেখা যাবে; খালি জায়গা থাকতে পারে।

none

Image-এর নিজের size রাখে।

scale-down

none বা contain-এর মধ্যে ছোট result নেয়।

img {
  width: 300px;       /* box-এর width */
  height: 200px;      /* box-এর height */
  object-fit: cover;  /* content কীভাবে fit হবে */
}
Valueসহজ অর্থ
fillপুরো box ভরো; প্রয়োজন হলে stretch/squash হতে পারে
coverপুরো box ভরো; crop হতে পারে
containপুরো image দেখাও; খালি জায়গা থাকতে পারে
noneনিজের size বজায় রাখো
scale-downnone/contain-এর মধ্যে ছোট result

3. object-position — কোন অংশ কোথায় থাকবে?

বিশেষ করে object-fit: cover করলে crop হয়। তখন object-position বলে কোন অংশকে অগ্রাধিকার দেওয়া হবে।

top

center

bottom

left

right

img {
  object-fit: cover;
  object-position: center;
}

/* Percent দিয়েও লেখা যায় */
object-position: 50% 50%; /* X=50%, Y=50% → center */
object-position: 0% 0%;   /* left top */
object-position: 100% 100%; /* right bottom */
object-position: 30% 70%; /* X=30%, Y=70% */
মনে রাখো: object-fit = “কীভাবে fit?”; object-position = “fit/crop হওয়ার পর কোন অংশ কোথায়?”

4. width + height — Box-এর মাপ

.photo {
  width: 300px;
  height: 200px;
}

এখানে image element-এর box 300×200। Original image ratio আলাদা হলে শুধু width/height সেট করলে distortion হতে পারে।

/* সাধারণ responsive image */
img {
  width: 100%;
  height: auto;
}

/* parent-এর চেয়ে বড় হতে দেবে না */
img {
  max-width: 100%;
  height: auto;
}
Difference: width:100% parent-এর পুরো width নেওয়ার চেষ্টা করে। max-width:100% parent-এর চেয়ে বড় হতে দেয় না।

5. aspect-ratio — Width : Height ratio

.box {
  width: 300px;
  aspect-ratio: 16 / 9;
}

300 ÷ 16 × 9 = 168.75px height। এটি image crop করে না; এটি element-এর box-এর ratio ঠিক করে।

Square

16 / 9

3 / 4

Moral: aspect-ratio = box-এর shape; object-fit = box-এর ভিতরের image-এর fit।

6. overflow — বাইরে গেলে কী হবে?

.avatar {
  width: 160px;
  height: 160px;
  overflow: hidden;
}

.avatar img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  transform: scale(1.1);
}

scale(1.1) image-কে বড় করে। overflow:hidden box-এর বাইরে যাওয়া অংশ দেখায় না।

Valueঅর্থ
visibleবাইরের অংশ দেখা যেতে পারে
hiddenবাইরের অংশ লুকায়
autoপ্রয়োজনে scroll
scrollscroll mechanism রাখে

7. Responsive Image

img {
  display: block; /* block-level behavior */
  max-width: 100%; /* parent-এর বাইরে যাবে না */
  height: auto;    /* original ratio বজায় রাখে */
}

Fixed frame/card image-এর জন্য:

.card-image {
  width: 100%;
  aspect-ratio: 16 / 9; /* frame-এর ratio */
  object-fit: cover;    /* frame পুরো fill */
  object-position: center; /* মাঝের অংশ priority */
  border-radius: 16px;
}

10. Final Practice Project — Profile Card

নিচের code-টি নিজে লিখে browser-এ চালাও। Bengali comment-গুলো দেখে বুঝবে কোন line কেন আছে।

<div class="profile-card">
  <div class="avatar">
    <img src="profile.jpg" alt="Profile photo">
  </div>

  <div class="content">
    <h2>Azim Ahmed</h2>
    <p>Aspiring Web Developer</p>
  </div>
</div>
.profile-card {
  width: min(100%, 600px);

  display: grid;

  /* ২টি column:
     প্রথমটি avatar-এর প্রয়োজনীয় জায়গা,
     দ্বিতীয়টি বাকি জায়গা */
  grid-template-columns: auto 1fr;

  gap: 20px;
  padding: 20px;
}

.avatar {
  width: 120px;

  /* 1:1 → square box */
  aspect-ratio: 1 / 1;

  /* গোল shape */
  border-radius: 50%;

  /* বড়/crop image বাইরে দেখাবে না */
  overflow: hidden;
}

.avatar img {
  width: 100%;
  height: 100%;

  /* image stretch না করে পুরো box fill */
  object-fit: cover;

  /* crop হলে মাঝের অংশ priority */
  object-position: center;

  /* image-কে block করা */
  display: block;

  /* চাইলে test করো */
  /* transform: scale(1.1); */
}

Practice Challenge

  1. cover → contain করো এবং difference দেখো।
  2. center → top করো এবং crop দেখো।
  3. 1 / 1 → 16 / 9 করো।
  4. overflow:hidden → visible করো, তারপর scale বাড়াও।
  5. width:120px → 200px করো।
  6. নিজের image দিয়ে card বানাও।

এক লাইনের Moral

“আগে BOX-এর size ও ratio ঠিক করো → তারপর image কীভাবে fit করবে ঠিক করো → crop হলে কোন অংশ দেখাবে ঠিক করো → বাইরে গেলে overflow ঠিক করো।”
