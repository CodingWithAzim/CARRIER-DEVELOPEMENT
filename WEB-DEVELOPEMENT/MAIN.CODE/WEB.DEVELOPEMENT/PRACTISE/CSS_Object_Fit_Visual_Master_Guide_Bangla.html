ORIGINAL IMAGE

সবচেয়ে জরুরি: width/height দিয়ে box-এর size আসে। object-fit box-এর ভেতরে image কীভাবে থাকবে তা ঠিক করে।

2. object-fit — একই image, একই box, শুধু value বদলাও

① fill

object-fit: fill;

পুরো box ভরবে। কিন্তু image-এর original ratio আর box-এর ratio আলাদা হলে image stretch/squash হতে পারে।

Moral: পুরো box fill, ratio নষ্ট হতে পারে।

② cover

object-fit: cover;

Image-এর ratio রাখা হবে। Box-ও পুরো ভরবে। তাই অতিরিক্ত অংশ crop হবে।

Moral: full box + no distortion = crop may happen.

③ contain

object-fit: contain;

পুরো image দেখা যাবে এবং ratio থাকবে। তাই box-এর কিছু জায়গা খালি থাকতে পারে।

Moral: whole image চাই → contain.

④ none

object-fit: none;

Image-কে box-এ fit করার জন্য scale করা হবে না। Image নিজের intrinsic size-এর কাছাকাছি থাকবে।

Moral: fit করো না, নিজের size রাখো।

⑤ scale-down

object-fit: scale-down;

Browser none এবং contain result compare করে ছোট result নেয়।

Moral: none বনাম contain → ছোটটা বেছে নেয়।

এক লাইনে: fill = stretch হতে পারে • cover = পুরো box + crop • contain = পুরো image + empty space • none = নিজের size • scale-down = none/contain-এর মধ্যে ছোটটা

↓

↓
Ratio নষ্ট করা যাবে না

Trick: cover = “BOX-কে cover করো” • contain = “IMAGE-কে box-এর মধ্যে contain করো”

4. object-position — cover হলে কোন অংশ থাকবে?

এখানে সবকটিতে object-fit: cover একই। শুধু object-position বদলানো হয়েছে।

top

object-position: top;

উপরের অংশ priority পাবে।

center

object-position: center;

মাঝের অংশ priority পাবে।

bottom

object-position: bottom;

নিচের অংশ priority পাবে।

left

object-position: left;

বাম অংশ priority পাবে।

right

object-position: right;

ডান অংশ priority পাবে।

img {
  object-fit: cover;
  object-position: center; /* crop হলে কোন অংশ থাকবে */
}
মনে রাখো: object-position box-এর size বদলায় না; crop হওয়ার পর image-এর visible position বদলায়।

6. aspect-ratio — এটা object-fit নয়

.avatar {
  width: 160px;
  aspect-ratio: 1 / 1; /* square box */
}

aspect-ratio box-এর ratio ঠিক করে। object-fit ঠিক করে ওই box-এর ভেতরের image কীভাবে থাকবে।

Moral: aspect-ratio = box-এর shape • object-fit = image-এর fit.

7. overflow:hidden কেন?

.avatar {
  width: 160px;
  aspect-ratio: 1;
  overflow: hidden;
  border-radius: 50%;
}

.avatar img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  transform: scale(1.1);
}

scale(1.1) image-কে বড় করে। overflow:hidden box-এর বাইরে যাওয়া অংশ লুকায়।

Important: overflow crop rule নয়; এটি box-এর বাইরে যাওয়া অংশ দেখা যাবে কি না সেটা নিয়ন্ত্রণ করে।

8. Responsive Image — দুইটি common pattern

Pattern A: পুরো image দেখা দরকার

img {
  width: 100%;
  height: auto;
  max-width: 100%;
}

Pattern B: fixed frame + uniform crop

.card-image {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  object-position: center;
}

9. Final Practice Project — Profile Card

<div class="profile-card">
  <div class="avatar">
    <img src="profile.jpg" alt="Profile photo">
  </div>
  <div class="content">
    <h2>Azim Ahmed</h2>
    <p>Aspiring Web Developer</p>
  </div>
</div>
.profile-card {
  display: grid;
  /* Avatar-এর প্রয়োজনীয় জায়গা + বাকি জায়গা */
  grid-template-columns: auto 1fr;
  gap: 20px;
}

.avatar {
  width: 120px;
  aspect-ratio: 1 / 1; /* square */
  border-radius: 50%; /* circle */
  overflow: hidden;   /* বাইরে যাওয়া অংশ hide */
}

.avatar img {
  width: 100%;
  height: 100%;
  display: block;
  object-fit: cover;       /* পুরো circle fill */
  object-position: center; /* মাঝের অংশ রাখে */
}
  1. cover → contain করো।
  2. center → top করো।
  3. aspect-ratio:1/1 → 16/9 করো।
  4. overflow:hidden → visible করে scale test করো।
  5. transform:scale(1.2) যোগ করো এবং effect দেখো।

সবচেয়ে বড় Moral

আগে BOX-এর size/shape ঠিক করো → তারপর image পুরো দেখা দরকার নাকি box পুরো fill দরকার ঠিক করো → cover বা contain বেছে নাও → cover হলে object-position দিয়ে crop-এর জায়গা ঠিক করো → দরকার হলে overflow দিয়ে বাইরের অংশ নিয়ন্ত্রণ করো।
