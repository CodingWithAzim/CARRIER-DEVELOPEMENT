এই project-এর লক্ষ্য হলো Grid শুধু মুখস্থ না করে দেখে, বদলে এবং ব্যবহার করে বোঝা। প্রতিটি গুরুত্বপূর্ণ জায়গায় বলা আছে: কেন ব্যবহার করেছি + কী ফল + কোথায় ব্যবহার হয়।

মূল ধারণা

Rows + Columns = Grid

Grid হলো এমন একটি layout system যেখানে row (সারি) এবং column (কলাম) বানিয়ে item-গুলোকে নির্দিষ্ট জায়গায় বসানো যায়।

01

FOUNDATION

Grid আসলে কী?

আগে শুধু parent এবং child-এর সম্পর্ক বোঝো।

HTML

<div class="grid">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>

CSS

.grid {
  display: grid;
}
A
B
C

এখানে কী হলো?

display: grid; দিলে parent element grid container হয়ে যায়। তার ভিতরের direct child-গুলো grid item হিসেবে layout-এ অংশ নেয়।

সারমর্ম — এই জায়গার ব্যবহার

যখন parent-এর ভিতরে থাকা একাধিক item-কে সারি ও কলামের নিয়মে সাজাতে চাই, তখন parent-এ display: grid; ব্যবহার করি।

মনে রাখো: Grid শুরু হয় parent-এ display: grid; দেওয়ার মাধ্যমে।

19

RESPONSIVE GRID

minmax() + auto-fit + auto-fill

Responsive card grid বানানোর সবচেয়ে useful pattern-গুলোর একটি। 

.cards {
  display: grid;

  grid-template-columns:
    repeat(
      auto-fit,
      minmax(180px, 1fr)
    );
}
সারমর্ম — প্রতিটি অংশের কাজ

minmax(180px, 1fr): প্রতিটি card 180px-এর নিচে যেতে পারবে না, কিন্তু প্রয়োজন হলে available space-এর অংশ হিসেবে বড় হতে পারবে।

auto-fit: যতগুলো column সুন্দরভাবে fit করতে পারে, Grid সেই অনুযায়ী arrangement করে।

grid-template-columns কতগুলো column + তাদের size ঠিক করে।
grid-template-rows কতগুলো row + তাদের size ঠিক করে।
fr Available space-এর fraction।
repeat() একই track বারবার লেখার shortcut।
gap Rows ও columns-এর মাঝের space।
grid-column / grid-row Item কোন line থেকে কোন line পর্যন্ত থাকবে।
span কতগুলো track জুড়ে থাকবে।
grid-template-areas নাম দিয়ে বড় layout structure বানানো।
justify-items / align-items প্রতিটি cell-এর ভিতরে item-এর alignment।
justify-content / align-content পুরো grid-এর track-এর alignment।
justify-self / align-self একটি নির্দিষ্ট item-এর alignment।
grid-auto-flow Auto placement কোন direction-এ হবে।
grid-auto-rows / columns Implicit track-এর size control করে।
minmax() Track-এর minimum ও maximum size নির্ধারণ করে।
auto-fit / auto-fill Responsive automatic columns-এর pattern।
nested grid Grid-এর ভিতরে আবার independent grid বানানো।
এক লাইনে Grid: Grid = Rows + Columns + Placement + Alignment — বড় 2D layout control করার জন্য।
এই project শেষ করার নিয়ম:

প্রথম থেকে শেষ পর্যন্ত দেখে নাও → তারপর Experiment section-এর সব value নিজে বদলাও → তারপর Dashboard section-এর code দেখে নিজের একটি ছোট layout বানাও।

তখন Grid-এর property শুধু মুখস্থ নয়, কেন, কোথায় এবং কীভাবে ব্যবহার করতে হয় সেটাও clear হবে।
