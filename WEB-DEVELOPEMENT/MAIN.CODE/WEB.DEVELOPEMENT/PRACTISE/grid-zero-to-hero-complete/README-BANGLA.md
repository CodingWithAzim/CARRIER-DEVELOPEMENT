## খাতার মূল নোট

> CSS Grid = Rows + Columns + Placement + Alignment

> `display: grid;`
> → Parent-কে Grid Container বানায়।

> `grid-template-columns`
> → Column-এর সংখ্যা ও size ঠিক করে।

> `grid-template-rows`
> → Row-এর সংখ্যা ও size ঠিক করে।

> `fr`
> → Available space-এর fraction।

> `gap`
> → Row/column-এর মাঝের space।

> `grid-column` / `grid-row`
> → Item কোথা থেকে কোথা পর্যন্ত থাকবে।

> `span`
> → কতগুলো track জুড়ে থাকবে।

> `justify-items` / `align-items`
> → Cell-এর ভিতরে সব item-এর alignment।

> `justify-content` / `align-content`
> → পুরো Grid-এর track-এর alignment।

> `justify-self` / `align-self`
> → একটি নির্দিষ্ট item-এর alignment।

> `minmax(min, max)`
> → Track-এর minimum ও maximum size সীমা।

> `auto-fit` + `minmax()`
> → Responsive card grid বানানোর শক্তিশালী pattern।

> Grid মূলত বড় 2D layout-এর জন্য খুব useful।
