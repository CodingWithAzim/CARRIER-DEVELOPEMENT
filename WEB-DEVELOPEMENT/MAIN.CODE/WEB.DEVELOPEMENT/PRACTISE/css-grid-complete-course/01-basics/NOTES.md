# Basics

## 1. `display: grid`
Turns an element into a grid container.

## 2. Direct children
Only direct children become grid items.

## 3. `grid-template-columns`
Defines column tracks.

## 4. `grid-template-rows`
Defines row tracks.

## 5. `fr`
`fr` means a fraction of the available space after fixed requirements are considered.

Try:
- `1fr 1fr`
- `1fr 2fr`
- `200px 1fr`
- `100px 1fr 2fr`
