CSS PRACTICE

aspect-ratio: 1;

এই project-এ চোখে দেখে বোঝানো হয়েছে aspect-ratio আসলে কী করে।

মূল নিয়ম: aspect-ratio: 1; মানে Width ও Height সমান রাখবে।

01

সবচেয়ে সহজ উদাহরণ

এখানে Height লিখিনি। aspect-ratio: 1; দিয়ে বলেছি Width ও Height সমান রাখতে।

CSS

.box {
  width: 220px;
  aspect-ratio: 1;
}
220 × 220

কী হলো?

১. width: 220px;
↓
২. aspect-ratio: 1;
↓
৩. Height-ও 220px
↓
ফল: 220px × 220px

02

তুলনা করে দেখো

একটিতে Height সরাসরি দেওয়া, অন্যটিতে ratio দিয়ে Height ঠিক হচ্ছে।

A — Height সরাসরি

.box {
  width: 220px;
  height: 150px;
}
220 × 150

এখানে Height আমরা নিজের হাতে 150px বলেছি।

B — aspect-ratio

.box {
  width: 220px;
  aspect-ratio: 1;
}
220 × 220

এখানে Height লিখিনি; ratio থেকে Height হিসাব হয়েছে।

03

1 মানে কী?

aspect-ratio: 1; কে সহজভাবে 1 / 1 ভাবো। অর্থাৎ Width : Height = 1 : 1।

1 / 1 Width = Height যেমন: 200 × 200
2 / 1 Width দ্বিগুণ যেমন: 200 × 100
1 / 2 Height দ্বিগুণ যেমন: 100 × 200

04

Ratio বদলালে shape বদলায়

এতে বোঝা যাবে aspect-ratio শুধু square-এর জন্য নয়।

1 / 1

1 : 1
aspect-ratio: 1 / 1;

2 / 1

2 : 1
aspect-ratio: 2 / 1;

1 / 2

1 : 2
aspect-ratio: 1 / 2;

05

তোমার Card Project-এর সাথে মিল

তোমার CSS-এ একই নিয়ম এই জায়গাগুলোতে ব্যবহার হয়েছে।

Avatar

.avatar {
  width: 72px;
  aspect-ratio: 1;
}
72 × 72

72px width → 72px height

Card Glow

.card-glow {
  width: 220px;
  aspect-ratio: 1;
}
220 × 220

220px width → 220px height

Status Dot

.status-dot {
  width: 7px;
  aspect-ratio: 1;
}

7px width → 7px height

KHATA NOTE

খাতার জন্য সারমর্ম

aspect-ratio: 1; → Width : Height = 1 : 1

অর্থাৎ Width যত হবে, Height-ও তত হবে।

.box {
  width: 220px;
  aspect-ratio: 1;
}

/* ফল:
   width  = 220px
   height = 220px
*/

মনে রাখো: aspect-ratio: 1; = “Width আর Height সমান রাখো।”
