isolation: isolate;

এই demo-তে Card-এর ভিতরের ::before layer কীভাবে আলাদা stacking context-এর মধ্যে থাকে সেটা দেখো।

চোখে দেখে বুঝো

CARD
এই pink অংশটি
::before layer
OUTSIDE ELEMENT
আমি Card-এর বাইরে

এখন isolation: isolate; ON আছে।

.card {
  position: relative;
  isolation: isolate;
}

.card::before {
  content: "";
  position: absolute;
  z-index: -1;
}
সহজ ভাষায়:

isolation: isolate; বলছে — “এই Card-এর ভিতরের layer-এর হিসাব Card-এর নিজের আলাদা layering-এর মধ্যে রাখো।”

তাই ::before-এর layer বাইরে থাকা element-এর stacking-এর সাথে সহজে মিশে যায় না।

মনে রাখার সূত্র 🧠

isolate = আলাদা করা

isolation: isolate; = এই element-এর layering আলাদা করে দাও।
